# 账号与跨设备同步

目标：手机与 iPad 登录同一账号，联网后同步学习记录、词库、草稿、设置与原始录音。断网继续学习，Mac 无需开机。手机系统尚待确认；共享页面支持移动浏览器/PWA，现有 iOS 安装版使用相同协议。

## 服务与账号

- Supabase Auth 邮箱/密码登录、PostgreSQL 每账号一份版本化文档、私有 Storage 存储内容寻址的音频分块。保留现有 Vercel AI 服务；账号登录不自动授予现有私人 AI 配对令牌。
- 使用官方 supabase-js，客户端只配置项目 URL 和 publishable/anon key，绝不包含 service_role。iOS 会话存钥匙串；Web/PWA 使用同源存储。会话不进入学习备份。
- 提供登录、注册（按项目邮箱确认配置）与邮件验证码重设密码入口。私用部署可在控制台创建已确认的个人账号并关闭注册；公共部署必须配置 SMTP。不能承诺默认邮件服务可用于公开注册。
- 免费计划有配额和休眠限制，不承诺永久在线。录音分块 4 MiB，避免免费版 50 MB 单文件限制。保留完整 .epbackup 导出作为独立备份。

## 本地账号隔离与启用

- 旧 EnglishPilot IndexedDB 保持为本机空间。每个云项目和用户使用单独的 IndexedDB；切换需要页面重载，避免运行中混入另一个账号。
- 登录后仍留在本机空间。明确勾选云存储说明并点击启用后，才复制本机数据到账号空间或进入空的账号空间。复制通过一致事务读取，原本机数据保留。
- 退出后回本机空间，账号的离线副本保留。重新登录同一账号返回同一副本。其他账号不能读取该账号的数据或触发其同步。
- 云同步上传考试目标、学习记录、作文/对话、导入的词库和音频（包括录音）；不上传 API Key、AI 配对令牌与密码。用户可在启用前导出本机备份。

## 同步与数据保护

- 自动触发：页面前台每 60 秒检查、网络恢复、学习变更后防抖 10 秒；只在账号空间启用且会话匹配时进行。应用关闭后不承诺后台同步。
- 一致事务读取本地状态及音频，先计算 SHA-256 和清单，再上传缺失内容，最后以 expected_revision 的原子比较交换提交云文档。冲突时重新拉取，不做无条件覆盖。
- 三方合并使用上次确认的云文档为 base。单方变更直接采用；对象字段独立合并；有稳定 ID 的集合逐条合并。无法确定顺序的数组及同字段不同编辑标为冲突。同一 FSRS 卡的并发修改不拼接成虚假复习记录。
- 首次两端都有数据时保守提示冲突。全新空账号副本可接收云端。自动合并后的文档必须通过现有 State 和音频清单校验。
- 上传期间产生的本地修改必须保留：应用下载结果前，重新读取一致快照，将当前副本基于先前快照进行三方合并，并在事务内比较当前状态及 Blob，若已变则重试。不会把新编辑标成已同步。
- 冲突暂停自动同步，可导出当前本机副本与云端完整备份，之后明确选择保留本机或采用云端；选择需绑定当时的本地/云端版本，变化后重新检查。不自动删除云端历史音频；额度错误保留本地数据。
- 下载验格式、大小、SHA-256，全部验证后才进行本地事务更新。失败、离线、登录过期、账号变更不能清空本地数据。

## 权限与上线

- 表读取依赖 auth.uid() = user_id 的 RLS；写入只允许受限 RPC，RPC 从 auth.uid() 确定用户并以事务进行版本比较。禁止匿名访问和任意直接写入。
- Storage bucket 为 private；每个路径首段必须为当前 uid，只允许本人读取/新增，不允许普通客户端覆盖/删除历史内容。发布 key 不具有管理员权限。
- 配套 SQL、自助部署文档与验证脚本。实际云服务开通、凭据配置、两账号 RLS 验证和两设备在线验收完成后，才能声称已上线。
- 新服务注册条款、账户密码及个人数据上传的必要确认由本人完成；代码、迁移与合成数据测试先准备。

## 验证

测试合并冲突/删除/独立追加、账号 A/B 与 guest 隔离、音频分块和损坏、CAS 并发、传输中编辑、首次云端恢复、离线与会话失效。现有测试、类型检查、原生资源构建和 iOS 模拟器编译必须继续通过。真实双设备测试需云项目可用和手机系统确认。
