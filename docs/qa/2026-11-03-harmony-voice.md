# 鸿蒙内置英语声音验收 · 2026-11-03

在 HarmonyOS 6.0.0.48 手机模拟器上，系统列出的 Laura 模型尚未安装。模型服务收到 HTTP 200 后返回解析错误 11500100，应用收到声音下载错误 1002300008。内置 SLT 语音使英语学习内容可以在这一环境中直接朗读。

- 设置页点击“试听内置英语声音”，真实播放器完成了 3.47 秒的朗读。
- 五句英语分段生成 19.415 秒单声道 16 kHz WAV。检查了数据长度和文件头，超过长度上限的输入被拒绝。
- 取消一段正在合成的长文本后，紧接着的新请求返回有效 WAV。
- 听力页选择 0.75 倍速播放全文，播放器按该速度播放。暂停、继续与停止均已实际操作。
- 123 项单元测试、8 项发布检查和 TypeScript 类型检查通过。调试 HAP 编译后覆盖安装到了 API 20 模拟器。

内置声音使用 [Flite 2.2](https://github.com/festvox/flite/tree/e9e2e37c329dbe98bfeb27a1828ef9a71fa84f88)，其源码和许可证随工程提供。系统英语声音下载安装后的实际播放、真人听感、真实账号跨设备同步与 AI 回复、华为手机签名安装仍待验收。
