# 账号同步开发验证

状态：实现已准备；Supabase 项目及真实双设备验收待完成。此记录不是生产上线声明，现有 v0.1.3 发布与 iPad 安装尚未更新为账号版。

## 已验证

本轮 65 项应用测试、9 项后端测试、8 项发布检查与 TypeScript 检查通过。独立代码审查提出的恢复草稿隔离和同步状态提示问题均已修复并复核；真实云端及双设备检查仍按下方待办执行。

- 使用真实 fake-indexeddb / Dexie 事务测试账号 A、B、本机 guest 的独立副本；原本机数据不因首次启用而删除。
- 三方合并测试独立练习追加、草稿冲突、同一卡片冲突、删除 / 修改冲突、合并后设置约束及有序数组保守处理。
- 4 MiB 分块的跨块音频恢复、完整原始字节和 MIME 类型保留、损坏数据拒绝。
- 使用模拟的外部云传输和真实本地数据库测试：首次空设备恢复、CAS 竞争重试、上传期间继续输入、断网、登录状态变化、暂停冲突、过期的冲突选择及明确的云端恢复。
- 使用 PGlite PostgreSQL 引擎执行真实迁移 SQL（测试中提供 Auth / Storage 框架表），验证匿名与其他账号隔离、禁止直接更新、首建 / 更新比较交换。此项验证 SQL 语义，不替代托管服务的真实 Auth、Storage HTTP 与 RLS 验收。
- 页面前台 / 变更防抖 / 退出销毁的调度测试；服务地址和公开 Key 校验；官方 Supabase SDK 的请求边界；原生会话存储错误不降级到浏览器存储。
- 使用真实 Supabase SDK 和合成过期会话验证：网络刷新返回 503 时保留 refresh session，客户端仍只允许打开对应账号的本地副本；离线退出移除该项目会话，不影响其他项目。云端操作仍要求服务端验证用户。
- 独立审查修复：AI 教师恢复草稿按数据库身份隔离，guest 沿用旧恢复键，A / B 不读写同一缓存；本地编辑立即把“已同步”改为“待同步”，也处理其他标签页的变更通知。
- 本机浏览器打开首次页面，可直接展开账号恢复入口；没有云服务配置时明确提示，填写测试用 secret Key 被拒绝，未保存配置或发起学习数据上传。
- 新原生资源构建完成，生成 145 个资源；iOS 模拟器未签名编译 `BUILD SUCCEEDED`，包含新 Keychain 会话插件。未签名编译不代表真机安装或账号同步成功。

## 已知边界

- 需要网络；应用关闭后不承诺后台同步。免费项目可能因额度或无活动而暂停。
- Harmony 原生工程缺少安全账号会话接口，此版用手机浏览器；iOS 安装仍遵守 Apple 签名有效期。
- 邮件验证码恢复需要配置模板与 SMTP；默认 Supabase 邮件不能用于公开注册。
- 不自动回收云端历史音频块；完整 `.epbackup` 仍需定期导出。
