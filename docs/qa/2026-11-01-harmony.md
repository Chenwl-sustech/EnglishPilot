## 已修复的问题

1. DevEco 26 拒绝旧 `compileSdkVersion`，移除覆盖后真实编译成功，没有提高应用最低版本。
2. 系统 Back 原来直接退出页面，现交给 ArkWeb 历史返回；原生测试从失败变为通过。
3. ArkWeb 默认未处理 `window.confirm`，提前交卷被取消；现使用本地来源限定的原生对话框，真实四节模考通过。
4. ArkWeb 英语 Web Speech 声音列表为空，加入 Core Speech Kit 离线英语适配、下载状态与错误提示；不使用静默或上传文本伪装成功。
5. 账号请求、AI 请求与长登录会话接入受限 HTTPS 和系统加密存储。移除需要特权的 Asset Store `IS_PERSISTENT` 标签后，普通应用存储及重启检查通过。

## 模拟器差异与验收脚本

API 26 镜像录音曾只产生约 338 字节、极短时长的数据；同一应用在 API 20 镜像能够录制并完整播放约 5 秒，因此将 API 20 作为本次录音验证环境，API 26 异常仍保留记录。未在手机重现之前，不据此承诺所有系统版本正常。

`tests-harmony/` 通过 HDC、官方 UITest 与仅调试包启用的 ArkWeb CDP 测试实际安装应用。确认弹窗交由 UITest 操作，禁止 Playwright 默认自动取消干扰。脚本拒绝非本地模拟器目标，修改数据前检查 Harmony QA 学习者；HDC 即使返回零退出码但包含失败信息也会停止，不读取旧界面转储冒充新结果。

运行方式见 [鸿蒙开发说明](../harmonyos.md)。本机证据在 `.local/harmony-qa` 和 `.local/harmony-setup`，未上传个人资料。需在真机补齐：签名覆盖安装、真实账号登录/刷新/退出、双设备冲突与音频同步、实际 AI 回复、离线英语声音和真人录音听感。


## 2026-11-02 审查修复与补测

一次独立整分支审查发现：整页重载不会销毁 ArkUI 宿主，原生 HTTP 请求可能继续运行。已增加网页 `pagehide` 取消、宿主 `onPageBegin` 清理／新建网络与语音实例，以及文档代次校验，阻止旧回复进入新页面。单元回归从失败变为通过；实际 HAP 回归确认重载取消 **8 个**在途请求，随后新请求正常收到预期匿名 401。修复后 123 项单元测试和类型检查通过。

API 20 的系统导出取消、导入取消也已验证：返回应用后已有录音数量不变。测试遇到系统首次键盘向导时，应先完成基本输入设置再操作原生界面；后台 CDP 页面可操作不代表前台没有系统遮挡。

当前交付仍为开发预览。保留 API 12 配置的决定避免无证据提高最低版本，但旧真机兼容性未由编译证明。使用 API 20 验证录音而保留 API 26 异常记录；不为模拟器异常替换已工作的共享录音实现。真实账号、系统英语合成、签名与听感均未补造通过结果，正式使用前需完成对应验收。
