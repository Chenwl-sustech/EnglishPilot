# Windows Codex 提示词：EnglishPilot 鸿蒙原生版

以下正文可直接复制给 Windows 电脑上的 Codex。请在用户自己的 Windows 电脑和华为设备上执行；不要把密码、密钥、令牌或个人学习备份粘贴到对话或提交到仓库。

---

你是我的开发搭档。请在这台 Windows 笔记本上持续开发并完成 EnglishPilot 的华为鸿蒙原生手机应用，目标是与此仓库当前 Mac 网页版 / iPad 测试安装版的用户功能、学习数据、交互和实际体验尽可能一致，能安全登录同一个学习账号并与现有设备同步，支持现有 AI 后端。对于平台确实无法实现的能力，给出明确的替代方式和差异；不要把构建通过、模拟测试或网页访问说成真机完整验收。请实际修改、构建、测试，遇到可自行解决的问题继续推进；仅在设备操作、本人登录/授权、证书签名或必要信息只能由我提供时简明询问。

## 正确获取代码

仓库是 `https://github.com/Chenwl-sustech/EnglishPilot.git`。当前账号同步和 iPad AI 代码在 `feature/account-sync` 分支，而不是默认 `main` / v0.1.3 Release。开始先获取该分支并记录实际 commit，检查是否存在更新或未提交修改，尊重既有工作，不要强制覆盖：

```powershell
git clone --branch feature/account-sync https://github.com/Chenwl-sustech/EnglishPilot.git
cd EnglishPilot
git log -1 --oneline
git status --short --branch
```

截至本提示词撰写时，功能代码基线为 `2b58be4`；分支可能有更新，请使用并报告获取到的最新提交。阅读仓库 `AGENTS.md`（如存在）、`README.md`、`docs/account-sync.md`、`docs/qa/2026-10-26-account-sync.md`、`docs/cloud-backend.md`，以及 `native/harmony/`、`native/ios/`、`src/lib/native/`、`src/components/account-sync.tsx` 和相关测试。以代码与真实测试为准，建立逐项对照表，再制定和执行方案。

## 环境与目标设备

1. 首先检查 Windows 版本、Node（工程要求 22+）、Git、DevEco Studio、HarmonyOS SDK、Hvigor 和磁盘空间。依照[华为 DevEco Studio 官方页面](https://developer.huawei.com/consumer/cn/deveco-studio)与针对所装版本的官方文档核对安装、API 和签名要求，不要编造依赖或绕过许可。当前工程配置 HarmonyOS `5.0.0(12)`；请核实已安装 SDK 和目标设备的兼容性后再调整，记录任何最低系统版本改变。
2. 确认我的华为手机型号、实际系统版本与开发者模式，并区分 HarmonyOS 原生（含 NEXT 等版本）与 Android 兼容应用；目标优先是手机实际支持的 HarmonyOS 原生 HAP。设备不在身边时先完成不依赖真机的工作，不要假称已验收。
3. 以 `npm ci` 安装锁定依赖，先运行 `npm test`、`npm run typecheck`、`npm run native:doctor` 等可用检查并记录基线；理解 `npm run native:build` 和 `npm run native:harmony:build` 后再执行，路径按 Windows 实际安装位置配置。用 DevEco Studio 打开 `native/harmony`，以其实际输出验证构建；缺依赖或签名失败要说明实际原因。

## 功能目标和重点缺口

- 对照现有页面与 iPad：首次设置、学习计划、词汇、题库与资源、语法、听力、阅读、口语、写作、小测、模考、错题、AI 教师、分析、日历、设置、深浅主题、离线学习和持久化。共享页面与已有题库尽量复用，保留第三方授权与来源；不要宣称题库覆盖全部雅思/托福官方题。
- 保持现有 ArkWeb 本地资源与离线能力，检查 `native/harmony/entry/src/main/ets/pages/Index.ets` 的资源拦截、CSP、来源限制与导航控制。当前实现会拦截非本地资源，账号和在线 AI 不能假定已经可用。设计受约束的原生网络访问和桥接，严格验证来源、目标地址、方法、数据大小、重定向及错误处理，避免直接放开任意 URL 或将服务器密钥暴露到网页。
- 账号登录：复用现有 Supabase 账号与云同步协议，实现符合当前 HarmonyOS 官方安全能力的会话/刷新凭据安全存储和隔离，核查生命周期、过期、离线打开、退出及恢复。当前 Harmony 原生工程尚缺安全账号会话接口；不要用明文 Preferences、localStorage 或日志存储敏感令牌。若 API 或设备不支持，说明并提供安全方案，不降级泄露。
- 同步：保留本机优先、学习空间隔离、离线修改、音频分块/完整性校验、并发冲突检测、备份两端与用户明确选择。先用合成数据验证手机与 Mac/iPad 双向同步，避免覆盖真实学习记录或自动选冲突版本；用户数据迁移和覆盖之前先保留完整备份。
- AI：复用现有账号授权/私人后端与模型额度机制，检查现有生产服务能力和可达性；iPad 的设备配对身份不能直接导出或复制。设计鸿蒙设备自己的安全认证或账号授权，服务器的 DeepSeek Key 和服务令牌绝不打包客户端或提交 Git。写作反馈与 AI 教师实际请求必须测试，明确 AI 文字发送范围、录音同步行为及潜在调用费用。
- 麦克风、权限拒绝后重试、口语录音与播放、导入素材、导出完整 `.epbackup`、系统文件选择、备份预览和恢复等，逐项实现并以合成数据核验。考虑手机和平板适配、竖横屏、可访问性与进程终止后数据恢复。
- 不要擅自卸载已有 App、删除或覆盖本地/云端数据、轮换生产密钥或重置数据库。私人登录、设备授权、签名资料由本人在官方界面操作；不要索要密码或要求我把 API Key 发给你。

## 验证与交付

按模块写有意义的自动化回归测试，覆盖授权与 Origin、桥接边界、离线/重连、账号隔离、冲突、文件与音频完整性，再运行现有测试、类型检查和真实 HAP 构建。使用 DevEco 模拟器做可执行的 UI 测试；有真实华为设备时，安装后验证登录、双向同步、录音/播放、文件备份恢复、断网和 AI 写作及教师回复。逐项记录：测试环境、预期、实际结果、是否真机、失败和未覆盖内容；不得仅依据代码或截图声称扬声器实际听感/权限工作正常。

生成明确标注的构建产物：区分未签名构建、开发者签名的可安装调试 HAP 与适合分发的正式包；记录签名/证书和设备限制。只有实际签名、安装并启动后才能称为可安装包。提供 Windows 从零操作说明、部署公开配置说明和故障排查，解释与 iPad 仍有差异的能力。不要将账号凭据、签名文件、用户数据、私有域名配对令牌等写进公开仓库或安装包。

最后整理变更与测试报告，检查许可证和敏感信息，提交到独立的鸿蒙开发分支并推送至我的 GitHub，提供分支/PR 链接与产物路径。未经完成真机验收和明确的发布条件，不声称已实现全部功能或发布正式版；记录剩余事项并继续处理可独立完成的工作。
